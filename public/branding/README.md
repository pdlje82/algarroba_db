# Algarroba community workspace identity

These are byte-preserving copies of the existing Algarroba brand assets from
`algarrobos/restoration_simulator/frontend/public/branding`. The old app is read-only;
runtime reads only the copies owned by this project. They are interface branding,
not botanical/source evidence or plant-image database associations.

- algarroba-symbol.png — SHA-256 `6754de72f4f7fde05f08e4930bd889bcfa9330b4a6b5c323a8bae3db53b9f4aa`.
- algarroba-wordmark.png — SHA-256 `49fa3453bc354aceb7fad4e3b93dc8a2225957530ce91cc340252a50f228b591`.

The workspace uses the original Carob & Clay palette, defined in
frontend/communityWorkspace.css: warm ivory, cream surfaces, forest green primary
actions, sage plant navigation, clay selection and water-blue research guidance.
Dark mode uses the original charcoal/brown-grey surfaces, sage actions and light clay
selection. The symbol retains its colors on an ivory tile; only the wordmark reverses.
